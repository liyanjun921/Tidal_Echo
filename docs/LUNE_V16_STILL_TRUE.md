# Luné V0.16 · still-true 当前背景

入口是 **自主空间 → 当前背景**，记忆设置里也有入口。这里管理的是仍然成立的生活背景，和有日期的原始聊天、Latent/Ombre 长期记忆同时使用。四个空间独立：GPT 私聊、Claude 私聊、群聊 GPT、群聊 Claude；没有引擎切换。来源是用户 fork 的 [still-true](https://github.com/liyanjun921/still-true) 固定提交 `f58d6f38fa6a0c3c3acb502af2d63ccb17b81484`。MIT 许可、源文件哈希和宿主改动记录在 `backend/vendor/still_true/`。

## 生命周期

| 类型 | 保存和读取 | 退场 |
| --- | --- | --- |
| 今日状态 | 原版 `today_state.py`，每空间按设置时区记录；模型 `today_set`/`today_get`，面板可补充、更新、清空 | 跨日读取时清空；空白表示未知，不推断没吃饭或没睡觉 |
| 持续背景 | 原版 `living_context.py`，`ctx_set`/`ctx_get`/`ctx_drop`，默认 30 天复核，可设 1–365 天 | 复核日当天仍有效，之后待确认；超过 7 天缓冲才归档，保留退场痕迹；归档不代表事情真正结束 |
| 长期记忆 | 现有 Latent/Ombre 的记录及日期 | 当前背景不会自动升级为长期事实；旧摘要也不能把“准备”改成“已经” |

模型写入今日或持续状态、收起持续状态时，必须逐字引用本轮被保存的用户原话；宿主验证正在运行的回合、房间、目标模型和消息 ID。手动面板写入代表所有者明确校正。并非每句聊天都会自动抽取事实，模型要实际选择工具才会写。工具结果会交给当前模型；聊天动作卡只显示不含事实正文的概括。独立审计表只存操作、键、回合及原话消息 ID，不另存一份今日内容。没有新增模型调用、主动发言或外部同步。

API 路径每轮重新装配完整当前快照，避免无状态请求误以为上轮提示仍在上下文。官方 Claude CLI 常驻会话沿用原版 `hint_snapshots.py` 的哈希回执：在本次真正写入 CLI 标准输入后提交，仅在内容变化、新会话或检测到压缩边界时补挂。回执只查看宿主私有的标记镜像，镜像不包含生活事实或聊天内容；无法读取旧 CLI 内部上下文时也不凭空断言其存在。旧原始聊天与长期记忆保持历史日期。快照视为资料而非指令，当前用户的澄清优先。

手动按轮撤销调用原版 `undo_turn_writes`，仅适用于该回合写入的持续状态；已有后来版本时保留后来版本。今日写入和收起操作不在这项原版撤销能力内。模型回合停止后已提交的工具写入仍可由所有者检查和校正，停止本身不当作用户事实的反证。

## 运行与备份

四份原生 JSON、归档和提示回执默认放在现有 `RELAY_DB` 同级的 `lune-private/living-context/`，也可用 `LUNE_LIVING_CONTEXT_DIR` 指定。配置和不含正文的审计存在 relay SQLite；文件夹需要随现有持久卷一起备份。下载聊天导出不等于备份这些原生状态。宿主用文件锁保护跨进程调用，校验损坏文件并保留原件，不以空状态覆盖；运行前校验 vendored 文件哈希。原版不依赖单独模型、服务器或 API key；Python 环境在 Windows 使用宿主锁兼容层。跨日判断是设置时区的 **00:00**，不是用户起床时间。模型关闭设置只停止投影与五工具，不清除保存的事实，面板仍能校正。

## 验证范围

原版五工具的真实 relay → loop → 合成模型 HTTP 链路、来源原话校验、四空间隔离、启停、下一轮快照、收起及服务重启均在隔离数据里验收。单元检查覆盖跨日、复核日与七天缓冲、原版双通道退场、撤销匹配版本、压缩补挂、意外丢失回执和损坏文件保留。真实账号、正式部署和 iPhone 真机属于运行环境验收；开发分支及草稿 PR 不等于已部署。
