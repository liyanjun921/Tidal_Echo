# Luné / OURSPACE V0.4 整合版

基于 Tidal Echo（AGPL-3.0），沿用用户提供的 Luné V0.3 Water Light / Lily Day 和液态玻璃 UI。LICENSE、NOTICE 和上游文档保留；原界面存于 `web/tidal-original/`。本次只引入最新版网页所需的处理后壁纸，不包含交接包里的原始参考图、历史截图或私人资料。

## 记忆与群聊规则

- GPT 私聊读取共享＋GPT 私有；Claude 私聊读取共享＋Claude 私有。
- 群聊读取共享＋群聊共同，双方私聊原文和私有记忆不会自动进入群聊。
- 记忆目前由用户主动新建或从用户消息点“记住这句话”；可编辑、删除，写入有版本冲突检测，服务端保留修改前快照。没有自动提炼、向量库或后台自我学习。
- 记忆最多选取 8 条、约 4000 字符；历史最多 24 条（可由上游设置调整），文本投影预算约 48000 字符。这是首版字符预算，不是精确 token 计数。
- 群聊默认 GPT、Claude 各回复一次；`@GPT` 或 `@Claude` 可指定对象，不自动互相无限续聊。
- 发送编号落库后可安全核对重试；中断不会自动重跑。停止会拦截迟到输出并在后续模型/工具步骤前检查状态，已经发生的外部操作不会撤销。

## 数据与凭据

这是**单主人私人部署**，所有设备持有同一个连接密钥；房间隔离针对模型上下文，不是多用户账号系统。模型密钥存服务端配置，不回显到浏览器。连接密钥默认只在当前浏览器会话保存，勾选后才长期保存在设备上。

JSON 导出包含三间房的记录与当前记忆，不含 API 密钥和附件二进制；完整备份需同时保存数据库、uploads 和配置文件。导入为追加合并，同一份备份只导入一次，不触发模型。V0.3 示例记忆被跳过；V0.3 原本的演示聊天需由用户自行筛选后迁移。

云端持久化和同一服务器多设备读取已经接入；尚无账号登录、端到端加密、离线编辑冲突合并、自动定时备份或跨数据库迁移工具。
