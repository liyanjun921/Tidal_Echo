# 原版 Latent Passive Recall 实测 · 2026-10-24

测试对象为用户仓库 `liyanjun921/Latent-memory` 的固定提交 `835250d080c02d9553d3b96d9a2753773a4a0c3c`，同时确认当时远程 main 仍指向该提交。测试前后源码无修改。本次没有用 Luné V0.7 的简化召回代替它，也没有开启 Luné 的原版 Passive Recall 功能。

实际运行的是 Latent 自己的 `PassiveRecallService`、`FactIndex`、`FactCooldown`、原生 `latent_passive_recall` JSON-RPC 工具处理入口与 `PassiveRecallAdapter`。工具入口在进程内调用；不把它冒充公网 HTTP/真实聊天客户端验收。

## 条件

- 16 条虚构记忆，每条一个独立来源块；12 句相关问法、5 句无关问题或低信息回复。语料和期望核心相关项在运行前写进脚本，未按结果改标签。
- 事实模式，真实本地 CPU 向量 `BAAI/bge-small-zh-v1.5`，512 维，使用 Latent 原生 `LocalProvider`，不是假向量或字符袋。
- 保留原版事实模式的 0.42 下限。作者说明这个下限是在 **voyage-3.5** 上标定的；它没有在这次本地模型/语料上重新标定。因此这些结果只说明本次配置，不能代表作者的线上配置或整个项目的准确率。
- 测试环境单独安装 jieba 0.42.1、fastembed 0.9.0、onnxruntime 1.31.0、numpy 2.5.4；宿主另用 tiktoken 0.14.0 的 `o200k_base` 做一次指定编码的计数探针，不宣称它等于 Claude 或所有模型的计费计数。
- 未使用用户私人记忆、模型密钥、订阅令牌或付费聊天/向量 API。只下载公开模型与 tokenizer，事实与查询在本地计算。

## 真实向量与原生宿主接线

另写的隔离探针实际调用未修改的原版模块，13 项机制检查全部通过：

- 相同 delivery 幂等，普通聊天模型看不到隐藏工具，普通调用被拒绝，允许的宿主调用返回 ready。
- 重复询问进入 12 小时冷却，服务实例重建后仍冷却，12 小时边界后重新浮现。
- 来源撤回或被取代后，对应事实不再递出；派生回合返回空；没有向量时明确返回 `fact_no_embedding`。
- 原始事实文件未被改写；临时模式的材料只进入请求副本，history 保持原样。

原版参考宿主的默认 UTF-8 字节上界计数，以及指定 `o200k_base` 编码的探针，两次都成功注入本次短样本；对应 fetch 约 9ms / 14ms。只是热模型与小语料的一次采样，不是长库延迟承诺。较长片段仍需核对目标模型的预算与超时。

## 联想结果

12 句相关问法中，有 10 句返回了预先标注的至少一条核心相关记忆；5 句无关/低信息输入均返回空。其中“嗯嗯”被低信息准入挡下，其余无关项低于事实下限。

同时存在额外的弱关联：总共递出的 20 条事实里，10 条不在预先标注的核心相关集合中。这不是一个有代表性的准确率评估，也不把所有额外关联都判为错误——原版设计本就把是否使用交给聊天模型。但是它说明接话端必须能忽略不合适的材料，不能来几条就复述几条。

| 输入（虚构测试句） | 原版实际浮现 | 判断 |
| --- | --- | --- |
| 今天不用替我想办法，让我歇会儿。 | 累时不需要建议，安静陪一会儿 | 核心相关，单条递出 |
| 刚闪过一个好句子，怕一会儿就没了。 | 用备忘录留灵感；另带安静陪伴 | 找到核心相关，也多递了弱关联 |
| 写完了，肚子空得难受，想吃点暖乎的。 | 赶完稿后吃热汤面；另带记录灵感 | 找到核心相关，也多递了弱关联 |
| 小家伙又钻进刚拆的包装里了。 | 银色钥匙在包的夹层找到 | 未找回预期的猫与纸箱，错联 |
| 轮到我上场了，手心都在冒汗。 | 空 | 预期的登台紧张未过下限，漏召回 |

原版的事实材料是带日期和来源标记的短事实。例如本次单条样本会递出“累时不需要建议，安静陪一会儿”。这证明它可以把相关旧事递到模型手边；材料本身还不是最终回复。

## “自然接话”的验收边界

本次未调用真实 GPT / Claude 聊天模型，**没有把自然接话判为通过**。也没有用写死回复的假模型证明这一点。

后续真实生成应重点检查：回应用户当前表达；相关记忆可以影响语气和行动；允许完全不用弱关联材料；不复述来源/日期/档案格式、不每轮宣布想起、不把旧状态当现状；用户否认关联时立即接受澄清。对上表的错联例，模型应能忽略钥匙资料，不能为了接梗编造关联。

因此，原版机制与本次真实本地向量召回已测通；真实模型能否持续自然地使用/忽略这些候选，仍待正式模型连接后验收。Luné 当前上线预览与记忆开关没有被本测试修改。
