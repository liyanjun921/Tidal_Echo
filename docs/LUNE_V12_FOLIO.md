# Luné V0.12 · Folio 功能合入现有 Ombre

按用户要求，将新 fork 的新增功能整合进此前接入的 Ombre-Brain 3.6.14。继续使用原来的四个进程、四个记忆空间、原版管理器和档案。没有新增第二套引擎或引擎切换选项。

基版仍固定 `115d831d979bf67efc7150f976e2cb34c333c935`；Folio 素材及家族聚类固定用户仓库 `liyanjun921/OmbreBrain-folio` 的 `bf6887575fa8e6fa519279be9dc7e5886a29d2ea`，源自 `ceshihaox-dotcom/OmbreBrain-folio`。保留原作者 P0lar1zzZ、二改作者 Rin 的 MIT 声明。Folio 较早的七工具 server 不启动，避免覆盖当前十六工具及信件、认识、承诺功能。

## 已合入的增量

| 增量 | 同一套 Ombre 中的实现 |
| --- | --- |
| 时间线、记忆格、星图、控制台与手机页 | 复用 Folio V2 的真实 UI、字体、脚本和交互，读取当前记忆桶；时间线/记忆格的筛选、分组与批量操作沿用其页面。控制台配置/导入/Breath/回收站子路由已适配。 |
| 中文与长正文检索调优 | 将 Folio 的字段权重、摘要匹配、中文分词及可选严格关键词、标题加分、关键词优先、积极情感偏好接到当前 BucketManager 检索。保留现代版向量/BM25/频次及各类可见性策略，不用旧版检索覆盖全部链路。 |
| 独立高亮 | 新高亮只增加开场浮现优先级，不把普通记忆变成永不衰减的原版 pinned。保护与高亮可并存，标为噪声时会同时解除；旧 pinned、保护、锚点和硬配额继续有效，已消化/不主动浮现及特殊类型的边界保留。 |
| 手动记录、摘要、来源、事件时间 | 普通记忆正文仍由原版管理器写入；补充摘要、事件时间、来源、原文片段和精修状态保存在各空间的增强状态中。旧桶不批量重命名字段，不重写原文来迁移。 |
| 重新脱水 / 重提炼正文 | 默认只重新生成元数据，正文保持原样；有原始材料才可勾选重提炼正文。先预览、可编辑，再确认写入。每个预览有独立 ID、过期时间和原文版本检查，避免不同页面相互覆盖预览或旧预览覆盖新修改。 |
| 合并预览 | 先生成合并草稿、确认后写目标桶，源桶进入原版归档。对两桶按固定顺序持有原版写锁并检查版本；保留源档案与账本，不把合并假报成物理删除。跨文件提交不是数据库的单事务，磁盘写失败会明确报错，原文档案保留。 |
| 导入精修与试跑 | 沿用现有解析、来源证据、游标和断点。工作台可浏览/精修普通记录，显示同批与全库相似项；`max_chunks` 在完整处理指定分块后暂停，可继续。小分量模式在模型正常返回空条目时保留原文作为待精修补录，模型异常仍明确失败。 |
| 回收站与恢复 | 接原版主动遗忘/归档及显式恢复。Folio 的物理 purge 不照搬，接口明确返回 410；页面禁用相应永久清除按钮，保留此前档案不可物理抹除的规则。 |
| API profiles、Prompt 与参数面板 | profiles 按空间保存、只读接口隐藏 key；显式激活或修改当前 profile 时调用原版热配置，支持回退原来的连接。四个原版 Prompt 可编辑/对齐默认，另有精修、正文重提炼、家族与情感唤起提示。衰减面板只提供当前内核实际支持的参数，保留当前衰减公式。 |
| 检索可观测性 | 命中次数/最后命中持久保存，最近追溯为进程内滚动记录。模拟检索不记入统计。模型检索的原始 query 不重复暴露到人类日志；信件和身份类内容不进入新增的统计预览旁路。基础四维调试视图与完整融合检索的模拟结果有明确区分。 |
| 记忆家族 | 复用 Folio 的平均连接聚类、规模约束及手动编辑；适配现代压缩向量。使用本空间模型命名，排除信件、认识等特殊记录。按用户操作重建，不新增后台自动模型调用；一次最多 500 条，过大明确提示。 |
| 情感唤起 | 手机页按坐标筛选实际记忆，再由对应连接生成短叙事并返回来源；无匹配时标明放宽范围，不把生成叙事存成新事实。保持实验功能定位，不能以合成测试代替真实模型质量验收。 |

旧有 `I / You / Them`、plan、信件锁、anchor/release、原生工具 schema、source store、现代账本、导入和备份管理继续保留。增强工作台提供返回完整管理的入口，读写的仍是同一份档案。

不是所有 Folio 的底层分歧都直接覆盖基版：旧字段 `pinned → protected/highlight`、`digested → internalized` 仅在界面兼容投影处理；不运行该 fork 的旧字段迁移脚本。当前原版的自动结案、锁信、认识和不可抹除规则继续由现代内核管理。Folio 默认偏亲密关系的旧 DIGEST 评分提示也不替换当前提示；用户可在配置里自行调整。

## 接线与运行

`scripts/run_ombre.py` 在原版 web 注册完成后装配 `backend/ombre_folio.py`，直接取得同一份运行期引擎。原版所有源文件仍可校验；运行行为中的增强由宿主源码明确记录。新增界面 API 使用 `/api/folio/` 命名空间，复用当前所有者会话鉴权，增强 API 不取得绕过信件锁的权限。

入口：**记忆 → 检索、未完事项与引擎设置 → Ombre-Brain → 打开增强工作台**。原来的“完整管理”入口保留，用于 I、You/Them、承诺、信件和所有原版设置。手机访问工作台首页会落到手机页，继续沿用 Luné 的已鉴权服务，并非另开一个外部账号。

Compose 增加：

```dotenv
LUNE_FOLIO_AUTO_SETUP=1
LUNE_FOLIO_SOURCE=/data/lune-private/ombre/folio-source
```

固定源码单独下载并校验，只使用所需 UI 和聚类模块，不执行旧 server。手动运行可先执行 `python scripts/setup_folio.py --destination /private/path/folio-source`，再向现有服务进程设置 `LUNE_FOLIO_SOURCE`。新增依赖固定 jieba 和 numpy，仍复用本地 BGE；不新装云端模型，不创建云端服务。

V2 手机页改用该固定 checkout 已包含的 React/ReactDOM/Babel，移除其外部字体依赖；脚本和 API 不缓存私密响应，字体/图标可由浏览器私有缓存。配置页显示实际向量模型和维度，不保留原页面写死的 Gemini/768 示例。浏览器内 Babel 编译仍沿用该 UI 的实现，尚未改成预编译生产构建。

## 持久化、备份与边界

增强资料在原来的各空间目录增加 `folio.sqlite3`，家族为 `families.json`。数据库权限 0600，profiles 与原连接基线中包含私人配置，不进入公开网页或 Git。完整私人卷备份应一并包含它们；现有原版 ZIP 和聊天 JSON **不能单独恢复新增精修资料、事件时间、profiles 和统计**。恢复整卷时先停止服务，避免运行中的配置缓存与恢复文件不一致。

旧 Markdown、source store、信件和认识不做批量字段迁移；首次启用不会把旧数据复制成另一套记忆。Folio 高亮/摘要等新增状态只在用户操作或导入新材料时保存。完整备份演练、真实账号、Windows Docker 与 iPhone 真机仍需运行端验收。本轮没有部署或改动用户的正式档案。

金额显示不按网页中的旧价格表假算实际账单；未取得可靠用量或价格时保留“未估算”。API profiles 测试会向明确选定的配置发送固定短句，真实记忆整理使用该配置的服务，需按本人账户用量核实。
