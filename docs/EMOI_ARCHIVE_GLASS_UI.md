# Émoi Archive Glass · 视觉和壁纸功能 v1

本文件描述**已写进 `web/` 的真实 UI**，不是效果图或尚未部署的云端承诺。方案源自用户提供的两类审美参考：①标本、档案、拼贴、细线、极简刊物排版；②深浅 iOS 液态玻璃、沉浸式风景、柔焦 UI。**图片不照搬参考作品**，本次内建 SVG 为原创插画。

## 视觉原则

- 艺术内容：钴蓝灰、雾白、细红线、植物/星轨、低对比印刷纹理、留白和宋体/衬线英文标题。
- 交互外壳：聊天气泡、发送键、页眉、抽屉、过滤器、阅读卡片、Room 小组件始终使用玻璃层，不牺牲文字可读性。
- iMessage 聊天：用户靠右蓝玻璃，AI 靠左浅白玻璃；连续气泡收紧间距；小字号状态行和圆形发送按钮。无须改变模型或消息协议。
- 深色模式单独调色；移动端保留安全区域；提供减少动画与高对比支持。真实 iPhone Safari 视觉仍需在部署后的 HTTPS/PWA 上验收。

## 用户如何更换壁纸

在 **聊天页** 点右上角的图片按钮：GPT、Claude、群聊各自独立存壁纸。打开 **记忆、共读、日记、日历、清单、影院、日报、健康、仓库、外观** 等功能页，点页眉右上角图片按钮，即可只改当前功能页。

可选预设：跟随全局、植物档案、星轨夜色、流动水光、百合晨雾、空白画纸。可以上传本机图片（JPEG/PNG/WebP/AVIF/HEIC，单张不超过 12 MB），也可一键恢复当前页默认方案。外观页原来的全局配色/玻璃透明度保留，未单独设置的页面可以跟随全局。原有自定义全局壁纸不会被删除。

默认分配：聊天、记忆、日记、共读、悄悄话偏植物档案；影院偏星轨夜色；日历、清单偏水光；健康偏百合。若用户之前选过非默认全局主题，先尊重原选择。所有页面都能覆盖这些默认值。

## 数据保存与安全边界

`web/emoi-wallpapers.js` 将每页预设 ID 储存在浏览器的 `localStorage`（`emoi-wallpapers-v1`）；图片储存在现有 `emoi-ui-assets` IndexedDB 的 `files` object store（`wallpaper-page:<context>`）。**壁纸不会自动上传服务器、共享给 AI，也不会同步到第二台手机**。文件存储受浏览器缓存/清理影响，应自行保留原图片；存储失败时原有设置和聊天记录不受影响。原 `custom-wallpaper`/Émoi global theme 与数据迁移代码继续存在。

本次没有改动任何 `backend/` 数据表、OB/Garden/CyberBoss 记忆处理、token、云端身份验证和模型请求。原本多房间的云聊天 API 保持不变。

## 样式与实现位置

- `web/emoi-archive-glass.css`：颜色、玻璃、聊天、抽屉、全屏功能页和壁纸弹窗的统一样式。
- `web/emoi-wallpapers.js`：每页/房间独立设置与本机图片存储，防止慢上传异步切页覆盖当前内容。
- `web/assets/emoi-archive-botanical.svg` / `web/assets/emoi-archive-nocturne.svg`：两套原创壁纸。
- `web/index.html`：按钮、样式和脚本接线。`web/app.js`：房间、页面切换时启用对应的壁纸。`web/sw.js`：PWA 离线资源。
- `tests/test_emoi_archive_glass.py`：预设资源、脚本引用和测试契约。

## 发布验收顺序

1. 在无真实密码的测试环境中分别打开三间聊天、记忆页和共读页，确认每页背景隔离，手机宽度 320/390、桌面宽度 1440 不横向溢出。
2. 在 A 页上传照片并切到 B 页，照片不得出现在 B 页；重新打开 A 页后仍显示；上传过程中切页不会把 B 页背景覆盖。
3. 在 iPhone Safari HTTPS 下验证图片上传权限、背景缩放、PWA 安装/更新、退出重开、深色模式、低动态和语音输入栏。
4. 真实服务器接入后验收聊天发送、记忆写入、Room、电影和 OB；UI 测试不能替代云端/微信联通验收。
