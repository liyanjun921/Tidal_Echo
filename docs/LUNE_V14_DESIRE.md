## 同一状态与完整数据流

主体为依恋、好奇、回味、责任、社交、亲密、压力、关系感、关系涟漪、保护、分离感和疲劳 12 维；保留此前 Wren 的表达、漫游、创作，共 15 维，界面用较中性的关系标签。疲劳是抑制闸。原来的九维偏移字典可惰性转成 schema 2 状态，仍存同一 `lune_wren_drives`，旧底色补齐新维度为零，不批量改聊天、Ombre 或 Latent。

`desire_kernel.py` 只接收状态、配置、时间和种子，不取系统时钟、不做 IO、不执行动作。`lune_desire.py` 负责真实消息、体验、操作证据、时间推进和持久化；`lune_wren.py` 继续负责房间投影与受限调度。

## 生物钟

每维偏移 `cap * amp * cos(2π*(hour-peak)/24)`，按房间时区读小时。默认参考 cap 0.08、最大允许 0.2；压力等参考振幅为零，所有维度的峰值/振幅都可在身体页调整。`drive` 仍是基础快照，`drive_display` 单独用于进度条和可选意图判定；`circadian` 返回偏移、相位表、当前小时和开关。关闭时 `drive_display == drive`，查看状态不写回基础。

V0.16 在“自主空间 → 此刻”加入时辰小卡：按后端返回的房间时区小时画钟面，显示当下偏移最大的三项和上升/下降幅度，并可直接跳到“身体”调整。关闭时明确显示暂停，不画出不存在的偏移；切换房间先清掉旧卡片，再读取新房间。小卡仅使用现有 `circadian` 快照，不自行计时、补写基础状态或推断真实情绪。此次上传的同名 PDF 的 SHA-256 与上方已接入的生物钟附件相同。

清晨脉冲独立作用于基础状态，每个本地日期最多一次；有固定峰时/宽度，并受疲劳和不应期抑制。`last_intimacy_at` 只由开启的明确亲近互动写入并持久化，余温用 3–14 小时窗口、最大增益 0.6；缺信号、太近或太久均为零。没有拿 2 小时指数尾迹假装撑过夜，也不会用生物钟自己的偏移反复刷新余温时间戳。

## 前端、开关与运行

此刻页绘制展示值、基础竖线与偏移箭头；身体页有分项开关、完整相位表、清晨参数、习惯/自驱计数、公开 E 与操作/数值变动账。状态仍来自鉴权 API。切换房间时清掉旧投影并停用保存，拿到新房间资料后才可提交；保存使用版本检查。页刷新、跨设备、服务重启不会把私有状态换成浏览器本机存储。

教程环境开关也作为新安装/旧设置尚无 desire 字段时的初值：`DESIRE_DRIVEN`、`DESIRE_COUPLING`、`DESIRE_BASELINE_DRIFT`、`HEARTBEAT_AUTONOMY`、`DESIRE_SELF_DRIVE`，以及 `DESIRE_HABITS`、`DESIRE_EXPERIENCES`、`DESIRE_NOISE`、`DESIRE_MESSAGE_PULSES`、`DESIRE_INTIMACY_PULSES`、`DESIRE_SEMANTIC_PULSES`、`DESIRE_CIRCADIAN`、`DESIRE_MORNING`。只接受 0/1，默认 0。已经由用户保存的空间配置优先；网页修改下一拍读取，代码升级仍需重启服务。没有暗中替用户打开主动发言或扩大供应商权限。

新增资料仍随私人 SQLite 完整备份：`lune_desire_changes/actions/experiences/classifier`、念头逐条来源与同一驱动状态。变化账保留每空间最近 10000 行；操作与体验持久保留，页面有读取上限。应用私有规则不能防止服务器管理员直接读取明文数据库。旧聊天 JSON 或单一记忆引擎 ZIP 不能完整迁移这些资料。

真实 HTTP 联调使用现有 supervisor、SQLite、固定 Latent/Ombre/Folio 与真实本地 BGE；模型与官方 CLI 使用合成供应商/协议进程。新增链路验证真实入站冲击 → 模型实际调用生活页写入 → 宿主操作证明 → E 写时快照 → 心跳消费 → 生物钟快照 → 实际唤醒落账回落。另用无关键词原话跑实际 BGE 分类，低置信可不匹配但不能假报就绪。多次 GET 不改变数据库基础、关闭生物钟完全回退、重启后门闸/念头/账/计时保留均通过，原记忆/日记/语音/工具链也回归通过。

浏览器使用上述合成 HTTP 结果的只读快照，核对 15 维箭头、身体设置、相位/清晨参数、体验与用量；没有声称浏览器直连 Python、Windows/iPhone 真机、真实账号账单、关系语气或长期主动质量已经验收。参考关键词、语义阈值、相位、漂移与表达参数仍须按真实使用校准；机制测试通过不证明它有真实生理或情绪。
