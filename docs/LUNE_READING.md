# Luné 共读书架

## 来源与边界

用户 fork 的 `liyanjun921/nest-bookshelf-ui` 在 `3f2baeb55484086aa003e59a300f1675d5e617ed` 展示了书架、阅读器、书中批注和双向留言的产品交互。原项目 NEST 书架 UI 由 nonchaiovo（Chai）创作，原仓库为 <https://github.com/nonchaiovo/nest-bookshelf-ui>。其个人非商业许可证禁止未经书面许可再分发源码、样式、素材、编译版本或基于它们的修改版，也禁止公开提供运行服务。因此本次没有复制或编译 NEST 的代码、样式、示例书籍、图片或文本。Luné 在已有共读功能上独立实现书架和读书流程；若以后需要原版视觉/源码或公开使用原作品，应先取得作者明确许可。

## 接入内容

| 功能 | Luné 实现 |
| --- | --- |
| 书架 | 继续阅读、在读／读完、标题搜索、房间范围筛选；现有 TXT/Markdown 导入和已有书籍无需迁移。 |
| 书籍详情 | 阅读状态、章节标题目录、按原文位置排列的页边批注和回复。书名及可见范围沿用现有编辑器。 |
| 阅读器 | 保存段落位置、从目录或批注跳转、字号和纸／雾／夜外观偏好。偏好只保存在本机。 |
| 共读 | 同一段选句存确切字符位置；同一条批注追加回复；可把选句与书籍 ID 带到对应的 GPT、Claude 或群聊房间。用户发送后，已连接的模型可用 `lune_workspace` 创建自己的批注或回复。模型不会在未连接、未发送时生成留言。 |
| 数据 | 继续使用 `book` 和 `annotation` 工作区记录及原有 SQLite、本机存储、导出导入、房间范围和版本冲突保护。旧的只有 `quote`／`para` 的批注继续显示。移动书籍范围或删除书籍时仍同步处理批注。 |

新增批注的 `data` 保存 `book_id`、`quote`、`para`、`start`、`end`、`color` 和 `replies`。服务端核对新引文与原文位置，回复只能追加且必须使用当前执行者身份。旧批注不要求补上字符范围。

## 使用

进入侧边栏的「共读」，导入 1 MB 内的 TXT/Markdown；选择书，点击「继续阅读」。在同一段里选中文字，再点「给选句写批注」。批注下可以继续回复；「问问 TA」会切到该书允许的房间，草稿可检查后发送。聊天模型要写书页留言时仍需连接服务端并实际调用工作区工具。

目前没有 EPUB/PDF 排版书籍导入，也没有跨设备同步阅读视口或凭空生成的 AI 共读文本。服务器连接时，书籍和批注可在同一服务器账户的设备间同步；本机离线使用则保存在当前浏览器。
